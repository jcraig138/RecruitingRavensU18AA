# Ravens U18AA · 2027-28 recruiting board

Password-protected, read-only scouting reference for the U18AA coaching staff,
published with GitHub Pages (`index.html`).

The page content is AES-GCM encrypted; the key is derived from the passphrase with
PBKDF2-SHA256 (600,000 iterations). Nothing is readable without it.

No contact details: player and family emails, phone numbers and correspondence
are deliberately excluded from the published file.

Coaches send feedback to James directly; the page is not editable.
